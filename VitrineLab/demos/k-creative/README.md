# K. — Portfolio créatif VitrineLab

Portfolio personnel de démonstration au style graphique audacieux : fond sombre, orange vif, typographie massive et compositions asymétriques.

## Fonctionnalités
- Navigation compacte avec menu déroulant
- Présentation personnelle et expertise
- Galerie de quatre projets de démonstration
- Formulaire de contact avec validation
- Préparation d'un message WhatsApp
- Mise en page responsive mobile / desktop

## À personnaliser avant publication
- Remplacer « Kévin » et le logo K. par le nom et l'identité du professionnel.
- Remplacer `hello@example.com` dans `index.html` par l'adresse e-mail réelle.
- Modifier `WHATSAPP_NUMBER` dans `script.js` (format international, sans +).
- Ajouter de vrais projets, images, descriptions, liens et témoignages.
- Adapter les compétences et les textes au parcours réel.

## Important
Les projets affichés sont des concepts de démonstration VitrineLab. Le formulaire ouvre WhatsApp et ne sauvegarde pas les demandes dans une base de données. Les coordonnées sont des valeurs de démonstration.

## Lancer
Ouvrir `index.html` dans un navigateur. Internet est requis pour charger les polices Google.
