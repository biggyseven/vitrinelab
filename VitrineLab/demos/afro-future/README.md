# AFRO FUTURE — Mini-site événementiel VitrineLab

Démo de site événementiel responsive, style éditorial immersif.

## Fonctionnalités
- Navigation responsive avec menu mobile
- Compte à rebours dynamique
- Programme de la journée
- Cartes d'intervenants
- Formulaire d'inscription avec validation HTML
- Préparation d'une demande d'inscription dans WhatsApp

## Personnalisation avant publication
1. Dans `script.js`, modifiez `EVENT_DATE` avec la date réelle de l'événement.
2. Remplacez `WHATSAPP_NUMBER` par le numéro WhatsApp de l'organisateur, au format international sans `+`.
3. Remplacez les intervenants, horaires, prix, adresse et textes fictifs dans `index.html`.
4. Ajoutez les vraies photos et informations légales de l'événement.
5. Pour confirmer et enregistrer les inscriptions automatiquement, connectez un backend ou un service de formulaire.

## Important
AFRO FUTURE, les intervenants, le lieu précis et les tarifs présentés sont fictifs et servent uniquement à la démonstration. Le formulaire ouvre WhatsApp : il ne réserve pas automatiquement une place et ne traite aucun paiement.

## Lancer
Ouvrir `index.html` dans un navigateur. Une connexion Internet est nécessaire pour charger les polices Google.
